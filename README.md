# Edis Alvarado · Trilogía Terepaima

Web estática bilingüe (español/inglés) con Hoy es y Mañana será, enlaces de Amazon, vídeos originales y 15 carteles descargables.

Abre `index.html` después de extraer el ZIP completo. Para actualizar GitHub Pages, consulta `LEEME-ACTUALIZACION.txt`.

## Archivos
- `index.html`, `style.css`, `script.js`, `translations.js`: base de la web.
- `actualizacion.css`, `actualizacion-data.js`, `actualizacion.js`: ampliación de libros y galería.
- `assets/carteles`: 15 PNG originales.
- `assets/miniaturas`: vistas WebP para la galería.
- `assets`: portadas, retratos, logo y vídeos.

No requiere instalación, backend ni compilación. Las imágenes conservan sus textos originales en español.
