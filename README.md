# Edis Alvarado · Landing del libro

Proyecto completo en HTML, CSS y JavaScript, preparado para GitHub Pages. Incluye la última versión responsive, español e inglés, banderas, fotografías, logotipo transparente, vídeos y enlaces a Amazon.

## Publicar en GitHub Pages

1. Descomprime este ZIP.
2. Crea un repositorio en GitHub (por ejemplo, `edis-alvarado`).
3. Sube el CONTENIDO de esta carpeta al repositorio, incluida la carpeta `assets`. `index.html` debe quedar en la raíz del repositorio, no dentro de otra carpeta. No subas el ZIP como único archivo.
4. En el repositorio abre Settings → Pages.
5. En Build and deployment selecciona Deploy from a branch, rama `main`, carpeta `/(root)` y pulsa Save.
6. Cuando termine el despliegue, GitHub mostrará el enlace de tu web.

Referencia oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Editar y probar

- `index.html`: estructura, contenido y enlaces.
- `style.css`: colores, proporciones, responsive y efectos.
- `translations.js`: textos en español e inglés.
- `script.js`: idiomas, presentación y controles de animación.
- `assets/`: imágenes, banderas y vídeos (incluye presentación adaptada a móvil).

No necesita npm ni compilación. Puedes usar Live Server en VS Code o ejecutar `python3 -m http.server 8000` desde esta carpeta y abrir http://localhost:8000.

Las rutas son relativas, de modo que funcionan en un repositorio de GitHub Pages con subcarpeta. La tipografía usa Google Fonts y necesita conexión. Las compras se realizan en Amazon.
