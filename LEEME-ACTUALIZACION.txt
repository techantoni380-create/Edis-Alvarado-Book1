PARA VER LA WEB EN TU ORDENADOR
1. Extrae el ZIP completamente. No abras index.html desde dentro del ZIP.
2. Entra en la carpeta Edis-Alvarado-Actualizado y abre index.html.
3. Si prefieres VS Code, abre esa carpeta y usa Live Server.

PARA ACTUALIZAR EL REPOSITORIO CON GITHUB DESKTOP
1. Conserva una copia de tu carpeta actual como respaldo.
2. En GitHub Desktop selecciona Edis-Alvarado-Book1.
3. Repository > Show in Explorer abre la carpeta correcta del repositorio.
4. Copia EL CONTENIDO de Edis-Alvarado-Actualizado dentro de esa carpeta.
   Acepta reemplazar los archivos coincidentes y combinar la carpeta assets.
   index.html debe quedar en la raíz del repositorio, no dentro de otra carpeta.
   Conserva la carpeta .git y cualquier configuración que ya tenga el repositorio.
5. En GitHub Desktop revisa los cambios, escribe «Actualizar libros y galería»
   y pulsa Commit to main; después Push origin.
6. Espera a que GitHub Pages termine su despliegue y recarga la web con Ctrl+F5.
